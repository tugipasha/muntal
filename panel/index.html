Apps Script Email Activation

Enable Automated Email Sending

Your Google Apps Script Web App needs the updated script code to send background emails directly from the server. You can send instantly via Gmail Web right now, or update your Apps Script deployment in 1 minute:
How to update your Google Apps Script Web App (1 Minute):
  1. Open your Google Sheet and click Extensions > Apps Script (Uzantılar > Apps Script).
  2. Select all code (Ctrl+A / Cmd+A), paste the updated code, and press Save (Ctrl+S).
  3. In the top function dropdown, select authorizeEmailAccess and click Run (Çalıştır). Follow the prompt to grant email permission.
  4. Click Deploy (Dağıt) > Manage Deployments (Dağıtımları Yönet), click the pencil icon (Edit / Düzenle), select Version: New version (Yeni sürüm), and click Deploy (Dağıt).
Once updated, background sending will deliver emails directly from your Google account.
